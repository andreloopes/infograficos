O preço para manter o relacionamento com uma inteligência artificial

"Namorar uma IA" acontece hoje de duas formas bem diferentes: pela assinatura de um app pronto — preço fixo, sem relação direta com o quanto se conversa — ou por um bot construído sobre uma API, como costuma rodar no Discord — aí o custo é por token e varia muito com o uso.

Apps prontos — preço fixo por assinatura

Nenhum desses cobra por token do usuário final: é tudo mensalidade. Dá pra namorar 24h por dia pagando o mesmo valor, dentro dos limites de uso de cada plano. Cotação: US$1 ≈ R$5,10 (11/ago/2026).

Bot próprio via API — o custo é por token

Quem monta um "namorado(a) de IA" no Discord, SillyTavern ou Chub paga por token consumido — e o histórico da conversa inteira costuma ser reenviado a cada mensagem, então quanto mais "memória" o relacionamento acumula, mais caro fica cada resposta. ▸Leitura para a matérialer mais

No uso leve ou moderado, montar o próprio bot via API sai mais barato que qualquer assinatura pronta — por isso tanta gente prefere Discord ou SillyTavern a pagar Replika ou Character.AI. Mas no uso intenso — o perfil mais comum entre quem chama isso de "namoro" de verdade, com conversas o dia todo — o custo pode ultrapassar os US$20/mês das assinaturas, especialmente em Gemini e Claude, que cobram mais caro por token de saída. O GPT-5 se mantém mais barato porque a OpenAI pratica uma tarifa de entrada bem mais baixa.

Sem "prompt caching" — recurso que reduz o custo do contexto repetido — o gasto do uso intenso pode ser ainda maior do que o calculado aqui.

Estes números são só a "conta de luz" do relacionamento: não incluem hospedagem do bot, nem os pacotes de gemas ou Charms que Replika e Character.AI vendem à parte para personalização.

▸ Metodologia e fontes

Metodologia: para o custo por API, foram usados três perfis de uso diário (leve, moderado e intenso) com número estimado de trocas de mensagem, tamanho médio do contexto reenviado a cada chamada e tamanho médio da resposta da IA; esses volumes de tokens foram multiplicados pelos preços oficiais de API de cada modelo (entrada e saída, por milhão de tokens) para chegar ao custo mensal. Para as assinaturas prontas, foi usado o preço fixo publicado por cada plataforma, já que nesse caso o usuário final não paga por token consumido.
